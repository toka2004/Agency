# Toka Creative Agency

A responsive, single-page creative agency portfolio built with semantic HTML, custom CSS, and Bootstrap components.

## Features

- Responsive navigation with a collapsible mobile menu that closes after selecting a link
- Agency introduction, feature highlights, project carousel, testimonials, news cards, and contact information
- Responsive layouts for mobile, tablet, and desktop screens
- Keyboard-visible focus states, a skip link, descriptive image text, and reduced-motion support

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5 (locally included styles and JavaScript bundle)
- Vanilla JavaScript (ES6+)
- Lato via Google Fonts

## Run Locally

This is a static site with no build step or package installation. Open `index.html` in a browser, or serve the project directory with any static file server.

## Project Structure
